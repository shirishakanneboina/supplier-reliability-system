### 2. Prompt History

The following entries are technically refined summaries of the main project-related requests made during development. They are not verbatim transcripts of every original prompt.

**Prompt 1 – Synthetic Data Generation**

Act as a Senior Data Engineer. Help design a Python-based synthetic data generation pipeline for a Supplier Reliability System. Generate interconnected supplier and business datasets with realistic relationships and export them into CSV, JSON, SQL and SQLite formats.

**Prompt 2 – Database Design and Validation**

Act as a Database Engineer. Help design a relational SQLite database for the generated datasets. Implement primary key, duplicate, null and foreign key validation, and verify table counts and database integrity.

**Prompt 3 – Supplier Reliability Scoring**

Act as a Data Analyst. Help develop a supplier reliability scoring methodology using delivery performance, inspection quality, invoice indicators and risk signals. Explain the scoring assumptions and limitations.

**Prompt 4 – Data Quality and Anomaly Detection**

Act as a Data Quality Engineer. Help identify inconsistent records, invalid relationships, shipment delays, inspection failures, overdue invoices and risk signals. Suggest appropriate validation checks.

**Prompt 5 – Interactive Dashboard**

Act as a Senior Python Developer. Help build a Streamlit dashboard connected to SQLite, featuring supplier rankings, KPIs, interactive charts, filters, anomaly monitoring and data downloads.

**Prompt 6 – Debugging and Testing**

Act as a Senior Python Engineer. Help diagnose execution errors, understand root causes, correct issues and verify data generation, database integrity and dashboard functionality.
