# AI Prompt History

## Project: Supplier Reliability Scoring and Data Generation System

### 1. AI Tool Used
- Tool: ChatGPT
- Purpose: Technical assistance, debugging, data engineering, database design and dashboard development.

### 2. Technical Prompts

**Prompt 1 – Synthetic Data Generation**

Act as a Senior Data Engineer. Design a reproducible Python-based synthetic data generation pipeline for a Supplier Reliability System. Generate interconnected supplier, purchase order, shipment, inspection and related business datasets with specified record counts, realistic relationships, edge cases and a fixed random seed. Export the datasets into CSV, JSON, SQL and SQLite formats.

**Prompt 2 – Database Design and Validation**

Act as a Database Engineer. Design a relational SQLite database for the generated datasets. Implement primary key, duplicate, null and foreign key validation. Verify table counts and database integrity.

**Prompt 3 – Supplier Reliability Scoring**

Act as a Data Analyst. Develop a transparent supplier reliability scoring methodology using delivery performance, inspection quality, invoice indicators and risk signals. Explain scoring assumptions and limitations.

**Prompt 4 – Data Quality and Anomaly Detection**

Act as a Data Quality Engineer. Identify inconsistent records, invalid relationships, shipment delays, inspection failures, overdue invoices and critical risk signals. Define validation checks and expected outcomes.

**Prompt 5 – Interactive Dashboard**

Act as a Senior Python Developer. Build a professional Streamlit dashboard connected to SQLite, featuring supplier rankings, KPIs, interactive Plotly charts, filters, anomaly monitoring and CSV downloads.

**Prompt 6 – Debugging and Testing**

Act as a Senior Python Engineer. Diagnose execution errors, explain root causes, suggest minimal corrections and define verification steps for data generation, database integrity, reproducibility and dashboard functionality.
